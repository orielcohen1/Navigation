📖 How to Use the Map Editor

Build your mall map step by step, export the JSON for the app, and generate printable QR codes.

① Set up floors

  • Click + Add Floor in the tab bar. Enter a short ID (e.g. G, U, B1) and a display name.
  • Click 📁 Floor Image (left panel or toolbar) to load a floor plan PNG/JPG as a background guide.
  • Set Map W / Map H to your coordinate scale (default 1000 × 620).

② Place nodes (waypoints)

  • Select Node ⊕, then click the map to drop walkable waypoints.
  • Put nodes at: every entrance, corridor intersection, escalator, elevator, and directly beside each store.
  • Switch to Select ↖, click a node, and give it a Label (e.g. "North Entrance") in the right panel — this shows on the app map.
  • Drag to reposition. Press Delete to remove. Press Esc to cancel actions.

③ Draw edges (corridors)

  • Select Edge ╌, click node A, then click node B — a corridor line appears.
  • Connect every pair of nodes that a user can walk directly between.
  • Click an edge with Select to highlight it; press Delete to remove it.

④ Assign QR codes

  • Select QR Code 🔲, then click any node where you will stick a physical QR sticker.
  • Enter a label (printed under the QR image, e.g. "North Entrance").
  • Not every node needs a QR — only locations where users will physically scan (entrances, key junctions).

⑤ Add POIs (stores & services)

  • Select POI ★, then click a node to attach a point of interest.
  • Fill in name, category, and icon — these appear in the app's search list.
  • A node can have multiple POIs (e.g. an intersection near both a café and a pharmacy).

⑥ Link floors (escalators / elevators)

  • Select Inter-floor ⇅, click the escalator node on the current floor.
  • Switch to the other floor tab, then click the matching escalator node on that floor.
  • The A* pathfinder will automatically route users across floors via this link.

⑦ Export & deploy

  • Click 💾 Export JSON — save the file as app/assets/data/mall_data.json and rebuild the Flutter app.
  • Click 🔲 QR Codes to view all QR images. Download as ZIP or print directly.
  • Print each QR, laminate it, and affix it at the exact node location in the building.
  • Use 📥 Import JSON to reload and continue editing an existing map.
